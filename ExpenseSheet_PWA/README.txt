EXPENSE SHEET - INSTALLABLE PWA

This version is prepared as a Progressive Web App (PWA).

IMPORTANT:
- Do NOT open index.html directly from a downloaded content:// or file:// URL if you want the Install App option.
- The folder must be hosted from HTTPS (for example GitHub Pages, Cloudflare Pages, or another HTTPS web host).
- After opening the HTTPS address in Chrome on Android, Chrome can show "Install app" or the app will provide an "Install App" button when supported.
- Your existing expense data is still stored in this browser's local storage. It is not automatically synced to Google Drive.

FILES:
index.html       - Expense Sheet app
manifest.json    - Android/PWA app information
sw.js            - Offline caching/service worker
icons/           - App icons
